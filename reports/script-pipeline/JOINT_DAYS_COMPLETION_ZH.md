## 2. 时间组合及正确的联合协方差

相对时刻固定为 `[0,24,120,144]` 小时。

旧H2：Apr6−5、Apr11−10；新H3：Apr6−5、Apr10−6、Apr11−10。
三个时间跨度是24、96、24小时。四天最多提供三个线性独立对比，不是六个独立实验。

若观测每一天的误差按既有假设独立，差分协方差是

`C_H = (H⊗I) diag(C5,C6,C10,C11) (H⊗I)^T`。

H3保留共享日期产生的 `−C6`、`−C10` 交叉块，统一计算整个向量的似然；没有把三条边各自当独立数据相乘。

## 3. GRMHD状态与曝光算子

已有141帧，cadence=8.893247544小时，跨度1245.054656小时。
可以构造124个覆盖四日和6小时曝光的重叠窗口。

- 背景：分段线性插值Stokes，先平均6小时IQUV，再取EVPA或相干孔径积分；
- 响应：`z=A exp(i phi)`，积分 `z(t) exp(i omega t)`，再形成各日与差分响应；
- 冻结状态：141张完整响应在四天共享同一幅相包络，保留确定性的轴子相位推进；
- 演化状态：124个窗口内响应随模拟时间变化；
- 单一状态同时决定全部空间特征和日期，不能逐像素分别挑快照；
- 各状态等权是明确的经验先验，不是141／124次独立观测，不除sqrt(N)。

积分对插值函数精确，**不代表6小时曝光被8.89小时cadence充分解析**。背景原始400²、响应100²，末端虽同为64²，仍记录原始分辨率差异。

背景默认去除模拟窗口的经验均值，形成零均值预测模型；另作固定非零均值控制。不是用观测日差反向对齐或消除信号。背景中原始角表示存在整数pi分支差，但所构造背景／观测的闭合winding均为零，没有静默删除这些窗口。

## 4. 误差模型的清楚区别

令 `lambda=c*b(alpha)`，联合生成形式是

`d = B + lambda*T(phase) + EHT_noise`。

Gaussian矩匹配允许

`C = C_EHT + C_B + lambda*(C_BT+C_TB) + lambda²*C_T`。

保留全协方差和logdet。另一类实验直接对有限完整状态的Gaussian观测密度加权平均，不人为把每个位置拆成独立响应扰动。

对照独立Gaussian模型时保留B和T的相同边缘矩，只消去B/T交叉矩；这样交叉相关效应与改变边缘方差可以分开。
联合经验B/T混合只加C_EHT，不再加Gaussian背景，避免背景重复计入。单独响应混合则加一个独立Gaussian背景，是另一明确生成假设。

统一标量背景的方差池在H2/H3都固定为相同H2来源，不因加入中间差分暗中重新调整该标量。

## 6. 为什么不采用最强的 .314 作为改进后的主结果？

它来自只用124个离散完整窗口支撑的联合经验B/T模型。

|峰值状态诊断|1D H2|1D H3|2D H2|2D H3|
|---|---:|---:|---:|---:|
|状态posterior ESS|1.702|1.001|1.325|1.008|
|最大单状态权重|74.5%|99.97%|86.2%|99.61%|

ESS在这里是保存的一个c/phase似然峰的条件状态集中度，不是整个后验的ESS。
H3在全网格最好的component quadratic也约为686.65（69分量）和1000.87（60分量）；这不是正式mixture goodness-of-fit或校准p值，但足以标记严重状态错配风险。

把窗口分成前后62个，H3的2D经验混合上限从全样本 .314，变为 .504／1.427；相对全样本最大变化约4.55倍。不能把 .314 当成可靠增加信息的收益。
其他全协方差模型也有窗口敏感性，例如1D H3演化响应＋Gaussian背景在前半／后半为 .717／2.116（全样本1.563）。因此不能只剔除一个异常模型就宣称其余全部稳健。
